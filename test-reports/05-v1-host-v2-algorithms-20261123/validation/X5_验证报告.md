## 俯视图比较

对每张图分别比较格子类型和 min、max、avg 三个高度字段的字节，三张图合计 1281 个结果全部一致。对照哈希来自先前 V0 对齐试验的 `/home/st/ini_code/pcl_Ini/work/v2-runtime-hardening-20261112/replay427-final/comparison/report.json`。本次重新在 X5 上通过 V1 完整工程使用的相同输入转换和 V2 调用类生成候选结果。底层输入使用 `/home/st/tmpDATA/stereo_data1` 的同一批 NV12/Q8 以及原试验的内参。

首轮把多个场景组连续送入同一个会话，地面自适应状态跨组延续，PCL、语义、融合逐格一致帧分别为 297、424、300。按原实验的独立场景组重建会话后，三项均为 427。这个差别与场景切换时的初始状态有关，板端在一次连续地图任务中会持续使用该任务的运行状态。

## 回充比较

两边在隔离进程按同一顺序处理 37 帧 1280×1088 NV12 控制样本，覆盖双码成功、单码与空白无效，以及进入有效状态前的过滤。这批样本用于可重复地验证 GDC 输入形状、原回充算法的结果和无效值转换。原版和 V2 的 `mark_ok`、`pose_ok` 以及输出坐标均逐帧一致，有效帧的三个浮点数精确到 FP32 位。无效帧在发布时返回三个 `999.f`。原始回充 SDK SHA256 为 `8e458ce9a48aa8555c2452e09b3edc57baa27fbe44a6db77ddbfc8fc751e9f0b`。
