5. 单位、GT处理及指标

GT1280_px = (R×65536 + G×256 + B) / 1000
GT640_px[v,u] = GT1280_px[2v,2u] × 0.5
GT有效：RGB24整数码 != 23（码0若出现仍为有效）
EPE = mean(abs(SDK−GT))
RMSE = sqrt(mean((SDK−GT)²))
bias = mean(SDK−GT)
Bad1/2/3：绝对差严格 >1/2/3 px
D1：绝对差>3 px 且 绝对差>5%×abs(GT)

GT先解码为float64数值再用最近邻精确采样；不直接缩放编码RGB图片，不混合无效码，不对视差范围做裁剪。SDK数值按Q8假设精确转float32；65535保留为正值并单独计数，未猜测为无效码。全像素汇总与逐图等权均值分别存于JSON；表格采用全像素汇总。

两个SDK单位条件不能通过拟合GT或“选择更小EPE”决定。若SDK生产端的Q8/256本来就是640像素单位，则条件A正确；若其数值仍对应1280像素单位，则条件B正确。RAW存储类型本身也须与生产端约定一致。主机离线评价耗时不是相机SDK推理时间。
