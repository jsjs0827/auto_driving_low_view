## 4. 生成并验证新归档

下面的宿主机命令给已核对的 `install/` 安装树建立一个独立的发布目录，保留原有目录结构。归档文件名使用本次实际打包时间。只要有一步失败，当前脚本便退出。

```bash
set -euo pipefail

pcl=/home/st/ini_code/pcl_Ini
install_dir="$pcl/work/robot-docker-sop-20261120/workspace/ai_ws/install"
release="x5-ai-ws-install-$(date +%Y%m%d-%H%M%S)"
stage="$pcl/delivery/$release"
archive="$pcl/delivery/$release.tar.gz"

for member in bin/ai_node lib/ai_node/libpercep_main.so \
              lib/ai_node/librecharge_mark.so config/ai_node/start_config.json \
              config/ai_node/recharge_mark.json model/mmyolo1105.bin \
              model/pidnet_1020_3classes.bin; do
    test -s "$install_dir/$member"
done

mkdir -- "$stage"
cp -a -- "$install_dir/." "$stage/"
python3 "$pcl/tools/safe_delivery_package.py" create --source "$stage" --output "$archive"
python3 "$pcl/tools/safe_delivery_package.py" verify "$archive"

(
    cd "$pcl/delivery"
    sha256sum -- "$release.tar.gz" > "$release.tar.gz.sha256"
    sha256sum -c -- "$release.tar.gz.sha256"
)
printf '%s\n' "$archive" "$archive.sha256"
```

打包源限定为本次的 `$stage`。按工作区交付规则排除本地共享内存实验及其衍生产物，且不得把镜像、sysroot、源码备份或日志放入这个安装包。若 `.deliveryignore` 命中或校验失败，停止交付并修正发布目录，再重新校验。历史归档只做只读检查。 [工作区打包规则](/home/st/ini_code/pcl_Ini/AGENTS.md) · [安全打包脚本](/home/st/ini_code/pcl_Ini/tools/safe_delivery_package.py)
