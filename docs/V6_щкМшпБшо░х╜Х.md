集成数据是两帧人工NV12和人工Q8，只用于确认调用链、几何和输出，不用于判断真实Stereo效果。检测/分割实际运行项目ONNX模型。集成验证包括：

- detseg_only 在右图/Q8路径不存在时仍执行，且没有点云/地图/新Stereo工作。
- original 保存了实际SDK映射产生的非空PLY；完整Q8前192行全0，底部352行与源人工Q8逐像素位值一致。
- ROI元数据为(0,192,640,352)，原Q8遮罩时间可读，原视差生成时间仍为null。
- 禁用分割时不读取分割模型，分割阶段耗时为null。
- 不可读BPU接口保持unavailable/null；关闭监控保持disabled，均不伪造0%占用。

编译的6个产物为SDK库、r36_compare_runner、r36_compare、r36_stereo_capture、perception_config、stereo_model_runner。未变的SDK核心复用v5实际交叉编译库；本轮改变的前处理、配置、比较和模型CLI均重新构建。用户的tools/build_x5_v6.sh仍执行完整SDK构建。

没有连接本次X5运行crop模型，未验证板端库是否与构建sysroot完全匹配，没有本轮真实Stereo精度/CPU/BPU/RSS结果；本机也没有真实ARM ROS underlay来链接在线ROS demo。在线provider的Horizon分支和standalone代码通过语法检查，相关几何共享已测试的helper。请在X5按使用说明运行两轮，生成实际结果。
